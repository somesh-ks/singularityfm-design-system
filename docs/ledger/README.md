# Design engineering ledger: the library's parts

The owner's asks and what was built for them, for the parts this repository owns and the taste that holds on every screen. How to work with the owner, the reversals and the surfaces that belong to the app's pages stay in the app repo:
[design-engineering-ledger.md](https://github.com/somesh-ks/singularityfm-app/blob/main/docs/design-engineering-ledger.md)
and [docs/ledger/](https://github.com/somesh-ks/singularityfm-app/tree/main/docs/ledger).

| File | What it holds |
| --- | --- |
| [taste.md](taste.md) | What the owner wants from any screen (section 1), and the phone's rules (section 11) |
| [look-tokens-type.md](look-tokens-type.md) | Hand-written CSS, tokens, type, radii, the 8pt grid |
| [components.md](components.md) | Buttons, chips, selects, dialogs, cards, one fix at a time |

A new design ask about a component or a token goes in one of these files, as a row with its decision number. A rule in taste.md that an agent must follow on every screen goes in the package's [foundations.md](../../packages/design-system/tokens/foundations.md) too, in one line.
