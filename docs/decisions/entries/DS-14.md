## DS-14: agent readiness is scored on the agent-ready rubric and tested with Claude runs on the owner's computer; the CLI, not an MCP

- Status: active; supersedes the 2026-11-12 agent-access plan's order (Next item 6 of docs/state.md before this record)
- Date: 2026-11-13
- Decision: the owner's answers on plan v2 (https://claude.ai/artifact/CUefDiCgrGCqxPvM1SzEdX, 2026-11-13).
  - Scorecard: the agentreadydesign.com rubric (v0.1, MIT), scored strictly: a level counts only when it and every level below it fully hold. A fresh agent rescores blind at the end of each plan step and its disagreements are listed. Supernova's 5 checks stay an outside number, rechecked at each release.
  - Outcome test: about 8 intent-level tasks that never name a component, run with `claude` on the owner's computer on his own sign-in (no API keys), weekly and at each release; Claude only. Mechanical grading first; a model judge only when he opts in. A baseline run comes before the docs work, so each docs change is measured.
  - No secret task set: the tasks are frozen before docs work starts, a check stops docs from quoting task text, and new tasks from his latest real asks are added now and then. Transcripts and screenshots stay on his computer; only summary rows are committed.
  - CLI only for now: no MCP until he asks for one. Layout components come only if the agent tests show agents getting page layouts wrong.
  - The empty state becomes a package component and the sheet's form fields become Sheet styles (stills first); the page heading stays copyable pattern markup.
  - The outside design plugin the app turns on (impeccable) stays or goes on a test run with and without it.
- Context changed: the 2026-11-12 plan ordered CLI, docs, evals, MCP, plugin and put a remote MCP after 1.0.0. Scored on the rubric, the system's foundation floor is 0 (docs from three sources disagree; no layout building blocks), so the docs and checks come before anything new, and measuring them needs a baseline first. Atlassian's CLI beat their own MCP on time and tokens, and every agent we use has a terminal.
- Rejected: a home-made rubric or a summed score; running the Open Design System Bench harness (we copy its method); a model judge by default; Codex and Antigravity runs (owner, Claude only); a remote MCP now.
- Revisit if: a host without a terminal (a chat or prototyping tool) needs the system, or the tests show agents skipping `ds` while an MCP would be loaded for them.
