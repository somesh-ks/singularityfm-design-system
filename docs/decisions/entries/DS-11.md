## DS-11: a page's restyle folds onto an existing option first; a kept deviation ships as an experimental option and is promoted or removed on usage

- Status: active
- Date: 2026-11-12
- Decision: the owner's rule for the reader's page overrides ("try sticking to consolidated component options as much as possible; once that is done, move them into the library; a deviation with a strong case can be a variant in an experiment library, so we can track the usage and see when to promote it"). The lifecycle is the thread's recommendation, given in reply to his "what's the best practice"; the numbers are its defaults.
  - Fold first. Each page restyle is mapped to the nearest option the component already has (a variant, a size, a state the component should draw itself). Where the fold changes the look, before and after stills go to the owner, who picks.
  - A kept deviation needs a written strong case: an owner call with its date, or a constraint no existing option meets. It ships in this package as an option of its component marked experimental (status, reason, date), not in a separate lab package and not on the page.
  - Promote to stable when it is used on 2 or more screens, unchanged for 4 weeks, and the owner agrees. Fold it into the nearest option, or delete it, when it is still on one screen after 8 weeks.
  - Usage is counted by the app's design-check report (DS-2), which reads the reader's markup; the library does not count its own use.
- Why: an option nobody else uses grows the system for one screen; a separate lab package is the one teams forget (it ships, nobody reviews it, it never graduates). A status on the option keeps it next to the stable ones, visible to `ds find`, and decided on a date.
- Rejected: one variant per override (about 15 new variants for 105 page rules, most of them one screen's taste); leaving the rules on the page (D253: a UI fix starts at the component).
- Revisit if: an experimental option passes 8 weeks without being promoted or removed, or the thresholds hold back an option the owner wants stable.
