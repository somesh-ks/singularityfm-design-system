## DS-15: the agent test runs the Antigravity CLI as well as Claude Code

- Status: active; amends DS-14 (its "Claude only" and its rejection of Antigravity runs)
- Date: 2026-11-13
- Decision: the owner asked for Antigravity to be enabled in the agent test (2026-11-13). `run.mjs --agents claude,antigravity` gives both agents the same frozen tasks in the same setups, graded the same way with no model call. The Antigravity CLI (`agy`) runs headless on his own sign-in, prompt as a stream-json event on stdin.
- Context changed: DS-14 kept the test to Claude so the first numbers stayed simple. Antigravity has a headless CLI with a stream-json transcript and reads AGENTS.md, so the same harness and grading can run it, and a second agent shows whether the docs help agents in general or only one. The project rule is that it must work without any one AI tool.
- Not equal, and recorded beside each result: `agy` runs with every tool approved, inside its terminal sandbox where the system has one, since its only allow-list is in the user's global settings, and it loads the user's global Antigravity rules and any memory it keeps; Claude Code runs with an allow-list, without the user's settings and with auto memory off. For both, git is told to push the reader's test copy nowhere, through the run's environment, not the owner's config.
- Rejected: changing the owner's global Antigravity settings to mirror Claude Code's allow-list; Codex runs (not asked for).
- Revisit if: `agy` gains a project-level or per-run permission list, or a run shows its sandbox blocking `ds` or `astro check`.
