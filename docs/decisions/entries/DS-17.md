## DS-17: Claude Code signs in to the CI agent test with GitHub's identity token, not a key

- Status: active; amends DS-16 (its Anthropic key)
- Date: 2026-11-14
- Decision: the owner found that Anthropic takes keyless sign-in from GitHub Actions (2026-11-14) and asked for the steps. The `claude` job of `agent-eval.yml` asks GitHub for an identity token with Anthropic's audience and renews it every minute into a folder the container reads; Claude Code trades it with Anthropic for a token of at most ten minutes (Workload Identity Federation) and keeps that in its config folder. The owner's federation rule accepts only this workflow file on `main` in the `agent-eval` environment of this repository, scoped to calling Claude in a workspace with a monthly spend limit. The environment holds the rule and organization ids as secrets: they are not credentials, but GitHub masks secrets in this public repository's logs and not variables. No `ANTHROPIC_API_KEY` is set, because a key would win over federation. Antigravity keeps its Gemini key (DS-16).
- Context changed: DS-16 took a key because that was the way in CI the owner had been offered. A stored key is valid until someone deletes it; a federated token dies within minutes of the job, and nothing for Claude Code is stored in the repository settings to leak.
- The container still gets one credential: the current GitHub identity token, which the agent can read and trade while the job runs, within the workspace's limit. It never gets the runner's request token, so it cannot ask GitHub for a token of its own. The antigravity job also holds the right to ask (one job runs both agents) and passes nothing of it to its container.
- Rejected: passing the request token into the container (the agent could mint GitHub tokens for any audience until the job ends); trading on the runner and passing a ten-minute token (a task runs up to fifteen minutes).
- Revisit if: Claude Code stops renewing the token over a long job, Anthropic changes the rule fields, or Google offers the same for the Gemini API.
