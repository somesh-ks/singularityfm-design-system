# Decisions made in the app repository

The design system's decisions before this repository existed stay in [singularityfm-app](https://github.com/somesh-ks/singularityfm-app/tree/main/docs/decisions), where they were made; a record there is never copied or rewritten here. These are the ones that govern the library. A new decision about the library is a DS record in [entries/](entries/); one that changes an app record below says "amends D<n>" in its status, and the app record is left as it is.
