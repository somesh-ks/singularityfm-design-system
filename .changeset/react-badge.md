Badge is a React component (DS-3): import it as `@singularityfm/design-system/Badge`, place it with `className` and give it its word or number as children. `Badge.astro` is deprecated but works as before, `class` and slot included, until a breaking release removes it, and `ds validate` warns on it. Markup and look are unchanged; it renders on the server and ships no script.
