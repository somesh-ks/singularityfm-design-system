Search field, picker search and wheel draw their keyboard focus ring unless the last input was a pointer, so a page without an input-mode script still shows keyboard users their place (with one, nothing changes). The search field keeps an edge in forced colours, a Toast's role settles before its words so an error after a status is announced, and `.create-fab-label`'s 4px margin is a named grid exception, so `ds validate` passes on the library's own styles.
